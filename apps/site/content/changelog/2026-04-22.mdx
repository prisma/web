## Prisma: a query plan cache size option and JSON equality fixes

Prisma ORM adds a parameter to size the query plan cache and corrects how equality is evaluated on JSON values.

## Prisma ORM

- **New** · [#29503](https://github.com/prisma/prisma/pull/29503): A new parameter sets the size of the query plan cache.

<details>
<summary>Fixes and improvements (3)</summary>

- **Fixed** · [#5806](https://github.com/prisma/prisma-engines/pull/5806): Case-insensitive equality on JSON values returns the correct result.
- **Fixed** · [#5804](https://github.com/prisma/prisma-engines/pull/5804): Equality checks on JSON list values behave consistently.
- **Fixed** · [#29499](https://github.com/prisma/prisma/pull/29499): The D1 adapter no longer attempts savepoint operations, which Cloudflare D1 does not support.
</details>
