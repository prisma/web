Today, we're launching the official [Prisma plugin for ChatGPT](https://pris.ly/gpt-plugin).

Instead of stitching together different tools to build and deploy an app, you can now do it through one ChatGPT plugin.

## What the plugin connects

The Prisma plugin connects ChatGPT to the [Prisma Stack](https://www.prisma.io/stack): [Prisma ORM](https://www.prisma.io/docs/orm), [Prisma Postgres](https://www.prisma.io/docs/postgres), and [Prisma Compute](https://www.prisma.io/docs/compute). ChatGPT gets the context it needs to write the data layer, create and connect a database, and deploy the result, without you switching between dashboards and CLIs.

## Try it with one prompt

Install the [Prisma plugin](https://pris.ly/gpt-plugin), open [Codex](https://chatgpt.com/codex), and ask:

> Build me a workout tracker using Prisma ORM and Prisma Postgres, then deploy it to Prisma Compute.

From there, ChatGPT can help build the app, set up the database, and deploy it through Prisma.
