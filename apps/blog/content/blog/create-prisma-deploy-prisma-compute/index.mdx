`create-prisma` now has a Compute path for new Prisma apps.

Run the initializer, choose a Compute-ready template, and the generated project can include:

- Prisma schema, client helper, seed file, database scripts, and env file
- `prisma.compute.ts` with the app's Compute defaults
- Prisma Postgres setup when selected
- Prisma Skills, Prisma MCP server, and editor add-ons when selected
- a `compute:deploy` script for later deploys

```bash
bun create prisma@latest
```

## Generated deploy defaults

For Compute-ready templates, deploy setup keeps the scaffold and deploy defaults in the same repo. The generated env file, app name, port, and framework feed the first deploy and later redeploys.

For a Hono app, `create-prisma` writes a config like this:

```typescript
import { defineComputeConfig } from "@prisma/compute-sdk/config";

export default defineComputeConfig({
  app: {
    name: "my-api",
    framework: "hono",
    httpPort: 8080,
    env: ".env",
  },
});
```

For a closer look at the TypeScript deploy config it generates, including how it scales to monorepos, see [Configure Prisma Compute deploys in TypeScript](/prisma-compute-config-file).

## Add-ons for agent work

The add-ons are optional, but the Skills add-on changes how an agent works with the repo. It installs Prisma Agent Skills from [`prisma/skills`](https://github.com/prisma/skills), including the `prisma-compute` skill for deploys, logs, domains, and the Compute workflow.

With that in place, an agent has Prisma-specific instructions for changing and redeploying the app without moving those instructions into the prompt.

## Redeploying

When you deploy through `create-prisma`, the generated project includes `prisma.compute.ts` and a `compute:deploy` script.

After making changes, redeploy from the project:

```bash
cd my-api
bun run compute:deploy
```

The script redeploys app code using the defaults in `prisma.compute.ts`. Database provisioning and migrations stay outside that deploy script.

For existing apps, use the Prisma CLI directly:

```bash
bunx @prisma/cli@latest app deploy
```
