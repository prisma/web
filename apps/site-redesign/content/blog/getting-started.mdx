Welcome to the platform! This guide will walk you through everything you need to know to get up and running.

## Create Your Account

Sign up with your email or connect with your existing Google or GitHub account. Once verified, you'll land on your dashboard.

## Set Up Your First Project

1. Click **New Project** from your dashboard
2. Choose a template or start from scratch
3. Configure your project settings
4. Invite team members

## Key Features

Here are some features you'll want to explore:

- **Analytics Dashboard** — Track key metrics in real time
- **Team Collaboration** — Share projects and assign tasks
- **Integrations** — Connect with the tools you already use
- **API Access** — Build custom workflows with our REST API

## Example API Call

```bash
curl -X GET https://api.example.com/v1/projects \
  -H "Authorization: Bearer YOUR_API_KEY"
```
