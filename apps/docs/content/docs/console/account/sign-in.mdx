You sign in to the [Prisma Console](https://console.prisma.io) to manage your workspaces, projects, and databases. This page covers the sign-in methods, how they connect to one account, and what to do when sign-in fails.

:::note[Looking for a different Prisma?]
This is Prisma from prisma.io: the TypeScript ORM, Prisma Postgres, and Prisma Compute, which developers use to build and host applications. Several unrelated products and companies also use the name "Prisma", such as student portals and time-tracking tools. Prisma support can't help with an account on any of those services. If you never created a database or app with Prisma, contact the service you meant to sign in to.
:::

## Sign-in methods

The login page at [console.prisma.io/login](https://console.prisma.io/login) offers three methods:

- **GitHub**
- **Google**
- **Email and password**

Workspaces created through the [Vercel Marketplace](/console/billing/vercel-marketplace) can also be opened from Vercel: **Open in Prisma** in the Vercel dashboard signs you in to the Console. There is no separate "Sign in with Vercel" button on the login page.

## Accounts with the same email

The Console matches accounts by email address. If you sign in with GitHub and later with Google, and both use the same email, you reach the same Console account with the same workspaces. When a new method is linked to your account this way, you receive an email titled "New authentication method linked".

This also applies to Vercel: if you sign in directly at the Console with the same email as your Vercel account, the Vercel Marketplace workspace appears in your workspace switcher.

If you see two separate accounts, the emails behind them differ. For example, your GitHub account's primary email may not be the address you used for Google. Check the email shown under **Account Settings > Profile** in each session.

## Reset your password

Password reset works only for accounts that already have a password.

1. On the login page, click **Forgot or need to set up a password?**
2. Enter your account email.
3. Open the link in the email you receive. The link is valid for 6 hours.

If you signed up with GitHub or Google, no reset email is sent, because the account has no password. Sign in with GitHub or Google instead, using the provider you signed up with.

## Add a password to a GitHub or Google account

You can't add a password to an account created with GitHub or Google yourself. Signing up again with the same email doesn't add one: the sign-up page says to check your inbox, but nothing is created. **Forgot or need to set up a password?** doesn't send an email either, because the account has no password to reset. Keep signing in with GitHub or Google.

Linking works the other way. To add GitHub or Google to an account, sign in with GitHub or Google using the same email address. The new method is linked to your existing account, and you receive a "New authentication method linked" email.

Prisma support can't add a password to an account either. Keep access to the GitHub or Google account you signed up with, because it's the only way to sign in.

## Sign-in errors

### "Too many requests"

The Console allows 10 sign-in attempts per minute for one email address. Further attempts in that minute return "Too many requests". Wait a minute and try again; the limit clears on its own.

There is no account lockout after failed attempts. If you can't remember your password, use the [reset flow](#reset-your-password) instead of retrying.

### "Multiple accounts use this email address. Please contact support."

This error means more than one account record matches your email, and the Console can't tell which one to sign you in to. You can't fix this from the Console. Email [support@prisma.io](mailto:support@prisma.io) from that email address and include the error text and the sign-in method you used.

### No account found, or no reset email arrives

- Check that you're using the email the account was created with. For GitHub sign-ups, that's the primary email on your GitHub account.
- If you signed up with GitHub or Google, sign in with that provider. Reset emails are only sent to accounts with a password.
- If you created the database from Vercel, open it with **Open in Prisma** in the Vercel dashboard, or sign in with the email on your Vercel account.

## GitHub organizations

Signing in with GitHub only reads your profile and email address. It doesn't need approval from your GitHub organization.

Repository access for Prisma Compute comes from the Prisma GitHub App, which you install when you connect a repository to a Prisma Compute project. The workspace owns the GitHub App installation. See [GitHub integration](/compute/github) for the connection steps.

To install the Prisma GitHub App on an organization, you need to be an organization owner. If you aren't, GitHub lets you send an install request to the owners from the install page. Prisma doesn't have its own approval step. After an owner approves the request, go back to the Console and connect the repository again.

The app asks for these repository permissions:

- **Contents**, read and write: to read your code and add deployment configuration.
- **Pull requests**, read and write: to open the setup pull request.
- **Workflows**, read and write: to add the deploy workflow.
- **Actions**, read and write: to start deployments.
- **Administration**, read and write: only used when you create a new repository from a template.
- **Metadata**, read.

If the Console says the installation needs updated permissions, open the link it shows and approve the new permissions in GitHub. If you aren't an owner, ask one to approve them.

## Common questions

### Can I sign in with email and password instead of GitHub?

Not on an account created with GitHub or Google. See [Add a password to a GitHub or Google account](#add-a-password-to-a-github-or-google-account).

### Why didn't I get a password reset email?

Reset emails are only sent to accounts that already have a password. If you signed up with GitHub or Google, sign in with that provider instead.

### I'm locked out after too many attempts. How long do I wait?

There is no lockout. Sign-in is limited to 10 attempts per minute per email, and the "Too many requests" message clears after that minute.

### I signed in with Google and see none of my workspaces. Where did they go?

You probably signed in with a different email than your original account. The Console matches accounts by email, so sign in with the method or address you used before.

### How do I change the email I sign in with?

The Console has no email-change setting. Follow [Change your account email](/console/account/change-email) to move your workspaces to a new address.

### I can't find my account and I don't recognize Prisma. What is this?

Prisma (prisma.io) makes a TypeScript ORM and hosts Postgres databases and apps for developers. If you were trying to reach a school, employer, or other app called "Prisma", contact that service directly.

### Who do I contact about "Multiple accounts use this email address"?

Email [support@prisma.io](mailto:support@prisma.io) from the affected address. Support has to resolve this error for you.
