Use `telemetry` commands to inspect and change anonymous CLI telemetry. Telemetry is on by default.

## Usage

```npm
npx prisma@latest telemetry status
```

## Commands

| Command             | Description                                            |
| ------------------- | ------------------------------------------------------ |
| `telemetry status`  | Show whether anonymous CLI telemetry is enabled and why |
| `telemetry enable`  | Enable anonymous CLI telemetry                          |
| `telemetry disable` | Disable anonymous CLI telemetry                         |

## Environment variables

`PRISMA_DISABLE_TELEMETRY=1` and `DO_NOT_TRACK=1` turn telemetry off for one run. The full list, and what to rename if you set `PRISMA_NEXT_*` variables for the early `prisma-next` command, is on [Environment variables](/cli/environment-variables).
