The `prisma platform` command group provides tools for interacting with the Prisma Data Platform.

## Usage

```bash
prisma platform [command] [options]
```

## Options

| Option         | Description          |
| -------------- | -------------------- |
| `-h`, `--help` | Display help message |

## Subcommands

| Command                    | Description                                |
| -------------------------- | ------------------------------------------ |
| `prisma platform status`  | Show Prisma Data Platform service status   |

## `prisma platform status`

Shows the current status of Prisma Data Platform services.

### Usage

```bash
prisma platform status [options]
```

### Options

| Option         | Description                          |
| -------------- | ------------------------------------ |
| `-h`, `--help` | Display help message                 |
| `--json`       | Output raw JSON from the status API  |

### Examples

Check service status:

```npm
npx prisma platform status
```

Output status as JSON:

```npm
npx prisma platform status --json
```
