Use `build` commands to inspect builds created by a Git push or the [Console](https://pris.ly/pdp).

## Usage

```npm
npx prisma@latest build logs <buildId> --follow
```

## Commands

| Command                | Description                                                                  |
| ---------------------- | ----------------------------------------------------------------------------- |
| `build logs <buildId>` | Stream logs for a build. `--follow` keeps streaming while the build runs. `--cursor <cursor>` resumes from a cursor a previous run reported |

Builds are started by a push to a connected repository or from the Console, not by a CLI command. See [`git`](/cli/git) for connecting a repository, and [Deployments](/compute/deployments) for how builds become deployments.
