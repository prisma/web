Use `branch` commands to inspect the platform branches of a project. The commands never create remote state. See [Branching](/compute/branching).

## Usage

```npm
npx prisma@next branch list
```

## Commands

| Command       | Description                                      |
| ------------- | ------------------------------------------------- |
| `branch list` | List platform branches for the resolved project    |
