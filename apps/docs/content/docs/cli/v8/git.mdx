`git` manages the GitHub repository connection. See [GitHub integration](/compute/github).

## Usage

```npm
npx prisma@next git connect
```

## Commands

| Command                  | Description                                                      |
| ------------------------ | ----------------------------------------------------------------- |
| `git connect [git-url]`  | Connect the resolved project to a GitHub repository; starts the GitHub App install flow if needed |
| `git disconnect`         | Stop push-triggered automation; keeps the project and existing branches |
