`db schema` reads the live database schema and prints it as a tree, or as the result document with `--json`. The command is always read-only: it never writes a file and never changes the database.

Use it when you need to inspect what Prisma 8 sees in the database before inferring, signing, updating, or debugging drift.

## Usage

```npm
npx @prisma/cli@next db schema --db "$DATABASE_URL"
```

## Options

| Option | What it does |
| --- | --- |
| `--db <url>` | Connects to the database. |
| `--config <path>` | Reads a specific `prisma-next.config.ts` file. |
| `--json` | Prints machine-readable schema output. |

## Examples

```npm
npx @prisma/cli@next db schema --db "$DATABASE_URL"
npx @prisma/cli@next db schema --db "$DATABASE_URL" --json > schema.json
```

## Related commands

Use [`contract infer`](/cli/v8/contract-infer) when you want to turn a live schema into a starter PSL contract. Use [`db verify`](/cli/v8/db-verify) when you want to compare the live schema with the emitted contract.
