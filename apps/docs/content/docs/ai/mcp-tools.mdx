These tools are available through the [Prisma MCP server](/ai/tools/mcp-server) in your selected workspace. Your AI client lists each tool's input parameters when it connects.

:::warning

Tools that change or delete resources can cause data loss or interrupt live traffic. Check the target workspace and resources before approving an operation in your AI tool.

:::

## Workspace and databases

- `fetch_workspace_details`: Fetch the details of a Prisma Postgres workspace.
- `list_prisma_postgres_databases`: Fetch a list of available Prisma Postgres databases for the user's workspace.
- `create_prisma_postgres_database`: Create a managed Prisma Postgres database and a new project.
- `delete_prisma_postgres_database`: Permanently delete a Prisma Postgres database by ID. This tool cannot delete a project's default database.

## Connection strings

- `list_prisma_postgres_connection_strings`: Fetch a list of available connection strings for the given database id.
- `create_prisma_postgres_connection_string`: Create a new connection string for a Prisma Postgres database with the given id.
- `delete_prisma_postgres_connection_string`: Delete a connection string with the given connection string id.

## Backups and recovery

- `list_prisma_postgres_backups`: List available automated backups for a Prisma Postgres database.
- `create_prisma_postgres_recovery`: Restore a Prisma Postgres database to a new database with the given backup id.

## Schema and queries

- `introspect_database_schema`: Read the schema of a Prisma Postgres database to show its structure.
- `execute_sql_query`: Run SQL to read, modify, or delete data in a Prisma Postgres database, without changing its schema.
- `execute_prisma_postgres_schema_update`: Execute a schema update on a Prisma Postgres database with the given id.

## Object Storage

- `list_object_store_buckets`: List object-store buckets in the workspace, optionally filtered by project id.
- `create_object_store_bucket`: Create a new object-store bucket in the given project.
- `delete_object_store_bucket`: Permanently delete an object-store bucket, all objects stored in it, and all its access keys.
- `create_object_store_bucket_key`: Create an S3-compatible access key for an object-store bucket.
- `delete_object_store_bucket_key`: Delete an object-store bucket access key. The key stops working immediately.

## Documentation

- `search_prisma_documentation`: Answer a natural-language question about Prisma using the official Prisma documentation, returning a cited answer with links back to the docs.

## Compute apps and builds

- `list_prisma_compute_apps`: List Prisma Compute apps in the selected workspace, optionally filtered by project.
- `list_prisma_compute_builds`: List builds, newest first, with optional project, branch, and state filters.
- `list_prisma_compute_deployments`: List deployments for a Prisma Compute app, newest first.
- `get_prisma_compute_deployment_logs`: Read runtime logs for a deployment, one page at a time.

## Compute deployment management

- `promote_prisma_compute_deployment`: Make a running deployment the live version of an app.
- `rollback_prisma_compute_app`: Make an existing deployment live, starting it first if it is stopped.
- `start_prisma_compute_deployment`: Start an existing deployment from an already uploaded build. This tool does not build or upload the app.
- `stop_prisma_compute_deployment`: Stop a deployment, disconnecting it from the app's public URL if it is the live version.
- `delete_prisma_compute_deployment`: Permanently delete a deployment, stopping it first if needed.
- `delete_prisma_compute_app`: Permanently delete an app. To stop and delete its deployments too, set `deleteDeployments` to true; otherwise, active deployments block deletion.

## Compute environment variables

- `set_prisma_compute_env_var`: Set an environment variable for a project's production or preview environment, or override it for one preview branch. Values are encrypted and never returned.
- `delete_prisma_compute_env_var`: Permanently delete an environment variable by ID.

## Composer projects

[Composer](/composer) defines your application's services, databases, and other resources in TypeScript.

- `get_prisma_composer_topology`: Show the saved connections between a project's Composer services and resources, with Console links and stored app URLs. The result may be out of date and does not check whether apps are running.

The Compute tools manage existing apps and deployments; they do not build or upload your source code. To deploy a new app, follow the [Prisma Compute guide](/compute).
