[Grok Bot](https://cursor.com/docs/grok-bot) is Cursor's app for persistent AI agents. Add the Prisma plugin to connect it to Prisma and use Prisma ORM 8 and Composer skills.

## Add the Prisma plugin

1. Select **Connect apps** in the sidebar, then search for **Prisma**.
2. Open the Prisma plugin and select **Add**.
3. Complete authorization in your browser and choose the Prisma workspace when prompted.
4. Check that the plugin account shows **Connected**.

## Work with Prisma

Ask the bot to work with Prisma Postgres, existing Compute deployments, or Object Storage. See [sample prompts](/ai/tools/mcp-server#sample-prompts) and the [tools reference](/ai/mcp-tools).

For code work, use the included `prisma-orm` and `prisma-composer` skills. See the [ORM skills guide](/ai/tools/skills#available-skills-for-prisma-8) and [Composer skills guide](/ai/tools/skills#available-skills-for-prisma-composer) for project setup.

For the Cursor editor, follow the [Cursor setup](/ai/tools/cursor).
