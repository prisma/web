The [Prisma plugin](https://cursor.com/marketplace/prisma) adds Prisma ORM 8 skills, Prisma Composer skills, and the hosted Prisma MCP server to [Cursor](https://cursor.com/).

## Install the Prisma plugin

1. Open **Customize** in Cursor and search for **Prisma** in the Marketplace.
2. Select **Install** and choose a project or user scope. You can also run `/add-plugin prisma` in Cursor chat.
3. When you first use a Prisma MCP tool, sign in to Prisma and choose the workspace the agent can access.

## Use the skills

Cursor selects relevant skills automatically. You can also invoke them in chat:

- `/prisma-orm`: Prisma 8 setup, queries, migrations, and upgrades.
- `/prisma-composer`: building and deploying Composer apps.

See the [skills guide](/ai/tools/skills#available-skills-for-prisma-8) for version-matched project skills, or [get started with Prisma 8](/getting-started).

## Use the Prisma MCP server

Ask the agent to work with Prisma Postgres, existing Compute deployments, or Object Storage. See [sample prompts](/ai/tools/mcp-server#sample-prompts) and the [tools reference](/ai/mcp-tools).

For an MCP-only connection, use the [manual setup](/ai/tools/mcp-server#cursor).

## Give Cursor project context

Open your project and include relevant files, such as `prisma.config.ts`, `contract.prisma`, and application code.

Add the [Prisma docs feed](https://pris.ly/llms.txt) to Cursor's documentation context for current references.

## Use the Prisma VS Code extension in Cursor

The [Prisma VS Code extension](https://marketplace.visualstudio.com/items?itemName=Prisma.prisma) also works in Cursor. Use it to manage Prisma Postgres databases and open Prisma Studio.

See the [extension setup](/guides/postgres/vscode) and [Studio guide](/studio/integrations/vscode-integration).

For Grok Bot, follow the [Grok Bot setup](/ai/tools/grok-bot).
