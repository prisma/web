Prisma Accelerate provides global caching for read queries using TTL, Stale-While-Revalidate (SWR), or a combination of both. It works with your own database once you enable Accelerate in the [Prisma Data Platform](https://console.prisma.io?utm_source=docs) and [configure it with your database](/accelerate/getting-started). Prisma Postgres has no query cache of its own: a Prisma Postgres database uses this cache only through a hosted Accelerate connection. Accelerate, including those connections, will be retired on December 1, 2026; see [Connect to Prisma Postgres without Accelerate](/postgres/database/switch-from-accelerate).
