[Prisma Studio](https://www.prisma.io/studio) works with or without Prisma ORM and supports the following workflows:

- Viewing and editing data in a spreadsheet-like interface
- Real-time schema introspection
- Reading the applied migration history of a [Prisma ORM](/orm) database
- Embedding directly into your Next.js applications
- VS Code integration for in-editor database management

## Supported databases

- PostgreSQL
- MySQL
- SQLite

## Quick start

```npm
# With direct database connection
npx prisma@prev studio --url="postgresql://user:password@localhost:5432/dbname"
```

Studio ships in the Prisma ORM 7 CLI — the Prisma ORM 8 CLI has no `studio` command — so the command pins `prisma@prev`. To run Studio in a Prisma ORM 7 or Prisma ORM 8 project, see [Getting Started](/studio/getting-started).
