## Installation

Prisma Studio comes bundled with the Prisma ORM 7 CLI. The Prisma ORM 8 CLI has no `studio` command. Make sure you have Node.js installed. Most of the commands below run the Prisma ORM 7 CLI with `npx prisma@prev`, which npm fetches on demand, so no global install is needed.

## Launching Studio

### With a Prisma Project

If you have an existing Prisma ORM 7 project, navigate to your project directory and run:

```npm
npx prisma studio
```

If you have a Prisma ORM 8 project, run Studio from a directory outside the project and pass the connection string: the Prisma ORM 7 CLI that ships Studio cannot read the Prisma ORM 8 `prisma.config.ts` and fails if it finds one. See [Studio with Prisma ORM](/studio/prisma-next) for the full workflow.

Export the connection string in your shell first. Run from outside the project, Studio does not load the project's `.env` file:

```bash
export DATABASE_URL="postgresql://user:password@localhost:5432/yourdb"
cd .. && npx prisma@prev studio --url "$DATABASE_URL"
```

This will start the Studio server and open it in your default browser. Studio prints the local URL it serves on.

### Without a Prisma Project

You can also use Studio with any database by providing a connection string:

```npm
npx prisma@prev studio --url="postgresql://user:password@localhost:5432/yourdb"
```

To read a [Prisma ORM](/orm) project's applied migration history in Studio, see [Studio with Prisma ORM](/studio/prisma-next).

## Connecting to your database

1. **Using environment variables**:
   Create a `.env` file in your project root with your database URL:

   ```
   DATABASE_URL="postgresql://user:password@localhost:5432/yourdb"
   ```

   Then run `npx prisma studio` in a Prisma ORM 7 project. In a Prisma ORM 8 project, Studio runs from outside the project and does not read this file: export the variable in your shell and run Studio as shown in [With a Prisma Project](#with-a-prisma-project).

2. **Using command line**:
   ```bash
   npx prisma@prev studio --url="your-database-connection-string"
   ```

## Basic Usage

### Browsing Data

- The left sidebar lists all your database tables
- Click on a table to view its data
- Use the search bar to find tables or columns

### Editing Data

- **Edit cells**: Double-click any cell to edit its value
- **Add records**: Click the "+" button to add a new record
- **Delete records**: Select records using checkboxes and click the trash icon

### Filtering and Sorting

- Click the filter icon to add filters
- Click on column headers to sort the table
- Use the search box to filter records by any field

## Common Tasks

### Viewing Table Relationships

- Related tables are shown as expandable rows
- Click the "+" icon to view related records

### Exporting Data

- Use the export button to download data as CSV or JSON
- Select specific columns to include in the export
