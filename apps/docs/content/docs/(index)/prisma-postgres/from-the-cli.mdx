Use the CLI when you want Prisma ORM and Prisma Postgres set up without leaving the terminal.

## Start a new app

You need Node.js 22.18 or newer on the 22 line, 24.11 or newer on the 24 line, or 26 or newer; Node.js 24 is recommended. The npm that ships with your Node.js release works; on Node.js 22 that is npm 10.

```npm
npm create prisma@latest
```

Choose PostgreSQL when prompted, and answer No to `Deploy to Prisma now?`. Setup adds `prisma-8.md`, installs project-level Prisma ORM skills for your coding agent, and writes the generated scripts used below.

## Create the database

Create a Prisma Postgres database from the terminal and export its connection string. The generated scripts read the environment variable, not `.env`:

```npm
npx create-db@latest
```

```bash
export DATABASE_URL="<the connection string create-db printed>"
```

The command also prints a claim URL; open it within 24 hours to keep the database in your account.

## Initialize the database

From the generated project directory, run:

```npm
npm run db:init
```

## Run the app

Sample users are seeded automatically on the app's first query.

```npm
npm run dev
```

## Add Prisma ORM to an existing app

If the app already exists, create the database as above, and then follow [Add Prisma ORM and PostgreSQL to an existing app](/prisma-orm/quickstart/existing-app/postgresql). That page runs `orm init` in your project, and in its step 2 you set `DATABASE_URL` to the connection string of your new Prisma Postgres database. A new database has no tables, and that page creates them from your contract.

If you point Prisma ORM at a database that already has tables, follow [Add Prisma ORM to an existing PostgreSQL database](/prisma-orm/add-to-existing-project/postgresql) instead.

## Import an existing database

- Use [Import from PostgreSQL](/prisma-postgres/import-from-existing-database-postgresql) when your source database is PostgreSQL.
- Use [Import from MySQL](/prisma-postgres/import-from-existing-database-mysql) when your source database is MySQL.
