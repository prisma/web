Prisma ORM 8 is a **release candidate**. It is published on npm and documented here, and the API can still change between release candidates.

## Current versions

| Package | Version on `latest` | What it is |
| --- | --- | --- |
| `prisma` | `8.0.0-rc.13` | the CLI |
| `@prisma/orm-postgres` | `8.0.0-rc.9` | the PostgreSQL runtime |
| `@prisma/client` | `7.10.0` | the Prisma ORM 7 client |

The CLI is released on its own line, so its release candidate number runs ahead of the runtime packages. The two numbers are not meant to match. Versions above were checked on 11 September 2026; run `npm view prisma version` for the current one.

## When general availability is expected

General availability is expected in October 2026.

## What happens to Prisma ORM 7

Prisma ORM 7 keeps receiving bug fixes and security updates for 18 months from the day Prisma ORM 8 reaches general availability. Its documentation stays at [/orm/v7](/orm/v7).

## What `npx prisma` gives you today

The `latest` tag on npm points at the Prisma ORM 8 release candidate for the CLI, and at Prisma ORM 7 for the client:

| Command | What you get |
| --- | --- |
| `npm install prisma`, `npx prisma` | the Prisma ORM 8 CLI |
| `npm install @prisma/client` | the Prisma ORM 7 client |

:::warning

A Prisma ORM 7 project that runs `npx prisma` without a version pin gets the Prisma ORM 8 CLI. That CLI does not read `schema.prisma`, and it has no `generate`, `migrate dev`, or `db push` command. Pin the version as shown below.

:::

## How to stay on Prisma ORM 7

Pin both packages in `package.json`:

```json title="package.json"
{
  "devDependencies": {
    "prisma": "^7"
  },
  "dependencies": {
    "@prisma/client": "^7"
  }
}
```

Run the CLI as `npx prisma@7` anywhere the version is not already pinned, including in CI and in one-off commands.

The Prisma ORM 7 documentation lives at [/orm/v7](/orm/v7), its setup paths at [/v7/getting-started](/v7/getting-started), and its CLI reference at [/cli/v7](/cli/v7).

## How to try Prisma ORM 8 alongside Prisma ORM 7

Both versions can run in the same application against the same database, with routes moving over one at a time.

- [Migrate from Prisma ORM 7 to 8](/guides/upgrade-prisma-orm/postgresql) is the five-phase guide for doing that on PostgreSQL.
- [Coming from Prisma ORM 7](/orm/coming-from-prisma-orm-7) maps every Prisma ORM 7 API to its Prisma ORM 8 form, and lists what has no equivalent yet.
